# Initialising Git

Git is a version control system that tracks changes to files and maintains a history of a project's development.

Running:

```bash
git init
```

Creates a hidden `.git` directory inside the project. This directory stores Git's configuration, commit history and tracking information.

Initialising Git prepares the project for version control. It does not automatically track files, create commits or upload anything to GitHub.

**Git vs GitHub:**
- **Git:** Manages version history locally on your computer.
- **GitHub:** Hosts Git repositories remotely, allowing you to store, share and collaborate on projects.
